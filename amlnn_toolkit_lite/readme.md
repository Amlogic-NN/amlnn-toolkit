# amlnn_toolkit_lite

`amlnn_toolkit_lite` collects lightweight Python inference SDKs for Debian boards. This directory focuses on local on-board inference and does not require a host PC or ADB-based remote inference workflow.

## Directory Structure

| Directory | Description |
| :--- | :--- |
| [amlnn_edge_toolkit_lite](amlnn_edge_toolkit_lite/readme.md) | Lightweight Python inference SDK for small models such as CNN models. It provides `.adla` model loading, inference, and performance profiling. |
| [amlllm_edge_toolkit_lite](amlllm_edge_toolkit_lite/readme.md) | Lightweight Python inference SDK for large language models. It supports streaming output, sampling parameters, and common model chat templates. |

## Use Cases

- Run `.adla` models generated by `amlnn_toolkit` directly on Debian boards.
- Integrate small-model or LLM inference into Python applications.

See the corresponding subdirectory for installation commands, example arguments, and API usage.
